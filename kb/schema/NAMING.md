# Naming decisions

Generated by `kb/gen_naming.py` from `cote_kb.db`, `ledgers/` and the
`entity_names` table. Every spelling on the site is a row in that table;
this page lists the rows the data does not settle, with the evidence for
each, so each one can be decided once and then only be data.

To apply a decision, edit `entity_names` (one row per entity), then
rebuild. No builder change is needed, and no other page has to be
touched: indexes, search, crumbs, citations and cross-links all read the
same row.

## 7. What is already settled

- Page titles, search, indexes, citations and scene links all read
  `entity_names`; there is no second spelling table.
- Ledger text is never rewritten: a quote keeps the spelling the
  walk transcribed, whatever the title says.
- Search is accent- and case-insensitive, so `Kikyou` and `Kikyō`
  reach the same page regardless of the decision above.
