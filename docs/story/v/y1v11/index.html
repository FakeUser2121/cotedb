Prologue: "The Monologue of Sakayanagi Arisu" p.7–12

Chapter 2: "The First Years’ Final Battle" p.27–54

Setting. Class C classroom on March 8.

Narrative beats

  • pp.27–29.
    • Chabashira announces the final special exam, the Event Selection Exam, after Yamauchi’s expulsion.
  • pp.29–36.
    • She explains the rules: each class proposes 10 events (with fair rules and tiebreakers), narrows to 5, and 7 are randomly selected on exam day
    • schedule runs through March 22.
  • pp.36–41.
    • Commanders are required and can intervene in events but are expelled if their class loses
    • class matchups are decided by raffle after commanders are chosen
    • class points change by 30 per event plus 100 for the winning class.
  • pp.42–46.
    • Horikita shares the event-rule handout

  • pp.46–54.
    • Sudō and Ike question Ayanokōji’s praise votes
    • Horikita explains Sakayanagi’s plan
    • Ayanokōji volunteers as commander, Shinohara objects, and Horikita supports Ayanokōji taking the role.

About these pages. rule-heavy explanation chapter with class discussion.

New names. none.

New rules and facts. Event Selection Exam: 10 proposed events per class, 5 submitted, 7 randomly selected; commanders required, may intervene, expelled on class loss; ±30 class points per event and +100 to winning class (pp.29–41).

Unattributed lines. none.

Translation errors, kept as printed. none observed.
