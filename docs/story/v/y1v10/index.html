Chapter 2: “The Class Vote” (pp. 30–84) — half 1 p.30–57

Setting. Class C classroom (March 2, supplementary exam announcement); cafe (Ayanokōji Group discussion).

Narrative beats

  • pp.30–34.
    • Chabashira announces the supplementary exam “The Class Poll” — each student casts 3 praise and 3 censure votes
    • the last-place student is expelled
    • a protection point (override an expulsion) goes to the top student.
  • pp.34–41.
    • Rules explained: votes invalidate each other
    • no self-votes
    • no abstentions
    • revote if all totals are zero
    • cross-class praise votes
    • 20 million points can override expulsion.
  • pp.42–51.
    • Kōenji provokes Sudō, arguing unnecessary students should be removed
    • Hirata mediates
    • Horikita silences Sudō
    • Horikita and Ayanokōji discuss the cruelty of the exam.
  • pp.52–57.
    • Ayanokōji Group at cafe: Keisei proposes mutual praise votes among the five
    • Airi worries about being targeted
    • Kōenji, Ike, Yamauchi, Sudō identified as likely censure targets
    • Horikita visits Ryūen to ask if he can survive.

About these pages. pp.30, 49 carry only page numbers (short pages); printed page numbers 25 and 44 appear on pp.30 and 49.

New names. none — all roster characters.

New rules and facts. Supplementary exam “The Class Poll” (pp.30–45); protection points (p.32); 20 million point override (p.46); cross-class praise votes (p.38); revote if all totals zero (p.43).

Unattributed lines. none — all speakers tagged.
