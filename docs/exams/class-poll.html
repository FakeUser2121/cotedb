      Class Poll

      special

      43 mentions · 8 vols · 2 runs · 3 claims

      Rules

      Class vote: each student casts three praise and three censure votes; praise minus censure is the result, self-voting and blanks are banned, voting repeats until first and last are determined, last place is expelled, and one dedicated praise vote must go to another class's student (full rule box y1v10 p.45; name and basics y1v10 p.37). The February 'provisional' rerun was debated by faculty before announcement (y1v11 p.13-18).

      Points

      Main run: no class-point changes came from the expulsions themselves (results board y1v10 p.315). Provisional run: class points were expected to fluctuate without any expulsions (y1v11 p.318).

      Conditions

      First run: last-place students in each class are expelled (y1v10 p.315). Provisional: no expulsions — defeated classes instead forfeit a protection point earned during the exam (aftermath y1v11 p.318).

      Organizer

      School-run supplementary special exam; faculty debate preceded the provisional rerun (Mashima objects that it risks expulsions, Tsukishiro insists, y1v11 p.15-18).

      Notes

      43 mentions / 8 vols (y1v10-y2v9.5). The y1v10 run produced three expulsions — Totsuka (A), Yamauchi (C), Manabe (D), none from B (y1v10 p.315) — the series' first mass-expulsion set piece; the provisional rerun is where Ayanokouji obtains a protection point (y1v11 p.37).

      Footprint

      • Span: y1v10 → y2v9.5
      • Anchored mentions by vol: y1v10 ×9, y1v11 ×10, y1v11.5 ×7, y2v2 ×4, y2v4.5 ×4, y2v5 ×7, y2v8 ×1, y2v9.5 ×1

      • Chronology: Named and explained in March of the first year ('The name of the special exam is the Class Poll', y1v10 p.37), then run to the volume's close.

      • Outcome: The posted results board records three expulsions — Totsuka Yahiko (Class A), Yamauchi Haruki (Class C) and Manabe Shiho (Class D), none from Class B — and no class-point changes (y1v10 p.315).
