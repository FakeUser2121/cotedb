      Survival and Elimination Exam

      special

      15 mentions · 4 vols · 1 runs · 1 claims

      Rules

      Named in its overview box '[Survival and Elimination Special Exam]' (y2v10 p.32): diversified tasks by category — each class chooses a category, selects a difficulty and issues a task to its target class in a set order; the name itself evokes expulsion (p.32), full name at p.144.

      Points

      Class points swing on placement; the losing side of the final standings absorbs the damage (Sakayanagi's class took the loss, y2v11 p.11).

      Conditions

      Elimination mechanics include a chosen dropout on the losing side: Kamuro Masumi dropped out (y2v11 p.11).

      Organizer

      School-run second-year special; task issuance runs through the class-representative chain.

      Notes

      15 mentions / 4 vols. Direct predecessor of the end-of-year special's high-stakes framing; the third-years' winter advice about forced expulsion quotas is retold against it (y2v11 p.197).

      Footprint

      • Span: y2v10 → y3v1
      • Anchored mentions by vol: y2v10 ×5, y2v10.25 ×1, y2v11 ×8, y3v1 ×1

      Runs

      • Chronology: The [Survival and Elimination Special Exam] overview is issued (y2v10 p.32) and the exam runs across the volume to its close (y2v10 p.144, p.197).
      • Participants: Sakayanagi's Class A, Ichinose's Class D, Ryuuen's Class C (takes the first attack, y2v10 p.144); Kamuro Minori (the class's sacrificial lamb, y2v10 p.197).
      • Outcome: Chabashira closes the completed exam (y2v10 p.197); Kamuro's loss ends in expulsion (y2v11 p.11).
