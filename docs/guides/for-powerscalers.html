Where the feats actually live

  • Winners, placements and consequences — every exam run with what it decided and the page it was stated on.
  • Points, prices and payouts — the numbers the economy moved on.
  • Expulsions and near-misses — every time the threat was real.
  • Exam chronology — the schedule the results sit in.

Read this before you argue

No page here ranks two characters against each other. The novels never state a power level, so any ranking is a reader's inference — and an inference printed as fact is the failure mode this archive was built to avoid.
