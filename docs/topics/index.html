How a topic page is built

A topic is a query over the line-by-line notes — the same notes that build the character and volume pages. Each note is one observation written against a page number, so a topic page can only be as broad as the volumes that have been read, and it says at the top how far they reach. Volumes not yet read simply do not appear.
