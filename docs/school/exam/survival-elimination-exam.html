Survival and Elimination Exam

special

Rules

Named in its overview box '[Survival and Elimination Special Exam]' (

y2v10 p.32
Survival and elimination? That sounds very dangerous...
In this special exam, there are diversified tasks based on categories prepared by the school. Each class will choose a category, select a difficulty, and issue a task to the target class in a specific order.
Year 2, Volume 10, page 32
): diversified tasks by category — each class chooses a category, selects a difficulty and issues a task to its target class in a set order; the name itself evokes expulsion (p.32), full name at p.144.

Points

Class points swing on placement; the losing side of the final standings absorbs the damage (Sakayanagi's class took the loss,

y2v11 p.11
Excuse me.
You're finally here. Have a seat.
Year 2, Volume 11, page 11
).

Conditions

Elimination mechanics include a chosen dropout on the losing side: Kamuro Masumi dropped out (

y2v11 p.11
Excuse me.
You're finally here. Have a seat.
Year 2, Volume 11, page 11
).

Organizer

School-run second-year special; task issuance runs through the class-representative chain.

Notes

15 mentions / 4 vols. Direct predecessor of the end-of-year special's high-stakes framing; the third-years' winter advice about forced expulsion quotas is retold against it (

y2v11 p.197
To comply with the government's policy, they'll make the rules more strict?
Last year, because there were no dropouts, it was forcibly changed from zero to one expulsion. I wouldn't be surprised if several people will get expelled in the upcoming end-of-year exam.
Year 2, Volume 11, page 197
).
