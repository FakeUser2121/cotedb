What the text says

  1. Rule Red-mark rule: a single failing score on the midterm means immediate, irreversible expulsion (Chabashira's announcement; relayed by Hirata when launching his study group). Y1V1 p.128–130, 152
  2. Rule Pass threshold: ≥32 points passes; <32 is a failing red mark. Y1V1 p.173
  3. Rule Test-bank asymmetry revealed: Class C knows the actual material differs from what Class D was told; Yamawaki taunts Class D for studying off-test material ("Why are you studying things that aren't even on the test?"). Y1V1 p.220–224
  4. Fact Chabashira admits the topics **changed the previous Friday** and she "forgot" to inform Class D; issues revised textbook page numbers by hand. The other teachers' indifference marks it as institutional, not human, error. Y1V1 p.225
  5. Effect One week lost; revised scope is mostly pre-group material the trio never learned; Sudou responds by suspending club activities for the final week. Y1V1 p.224–227
  6. Fact Post-admission mock papers are **verbatim identical across years** ("Every single word is identical") — the final three problems (2nd/3rd-year difficulty) repeat exactly. Y1V1 p.232–233
  7. Fact Thursday: old-test sheets distributed class-wide by Kushida (AK's prints); cover story holds; class morale spikes; sheets withheld from other classes. Y1V1 p.236
  8. Fact Question verification: social-study questions are the same as the old exam — the pipeline works; Horikita's lesson predictions also matched Japanese and chemistry content; the hard math set is identical to old exams (memorized answers usable). Y1V1 p.241
  9. Fact Subject order: social studies → Japanese → chemistry → mathematics → English; Sudou's English gap (slept through its review) turns the final test into a solo survival scene. Y1V1 p.241–243
  10. Rule Summer reward: passing BOTH this midterm and the July final with zero expulsions earns the whole class a summer-break vacation to a southern island. Y1V1 p.240
  11. Effect Immediate post-exam morale: Horikita acknowledges Sudou's effort publicly; group confidence in a mass pass. Y1V1 p.244–245
  12. Fact Results posted on blackboard: 10+ students hit perfect 100s in math, Japanese, and social studies. Y1V1 p.246
  13. Fact Sudou: 60×4 subjects, **39 English** → red-marked. The class pass line was **40, not 32**. Y1V1 p.246–247
  14. Rule True pass-grade algorithm: per-class threshold = class average ÷ 2, **rounded** (down 32 on the previous test from 39.8/64.4-derived inputs; up to 40 this midterm from 79.6 ÷ 2 = 39.8). Red mark below threshold = expulsion (withdrawal form + legal guardian). Y1V1 p.247–248, 250
  15. Fact Sabotage attempt: Horikita scored 51 in English on purpose (vs perfect in four other subjects) to drag the English average below 39.8 so Sudou would pass — defeated only by the rounding rule. Y1V1 p.249–250
  16. Fact The earlier scope change meant Class D tested under documented unfair conditions — acknowledged by Chabashira as "a microcosm of our unfair society"; appeal route declared closed "at this stage." Y1V1 p.251–252
  17. Fact Resolution: one English test point purchased for 100,000 points (AK + Horikita combined) → Sudou passes; expulsion rescinded. Y1V1 p.253–254
  18. Fact Class D passes en masse otherwise — the old-test operation delivered; everyone clears except Sudou's single red line. Y1V1 p.246, 248
