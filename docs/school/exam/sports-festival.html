What the text says

  1. Rule Classes A and D form the Red Team, Classes B and C the White Team, across all grade levels; Class D competes alongside Class A. Y1V5 p.17
  2. Rule Individual events score 15/12/10/8; fifth place loses one point and each place below loses one more; a team-competition win is worth 500. Y1V5 p.17
  3. Rule Recommended-participant events score 50/30/15/10; fifth loses two points and each place below loses two more; the 1200-metre relay pays three times those values. Y1V5 p.18
  4. Rule After combined class scores are reviewed, 100 class points are deducted from the first-, second- and third-year batches of the two classes on the losing team. Y1V5 p.18
  5. Rule Grade ranking is separate: 50 class points to each grade’s first-place class, no change for second, 50 deducted for third, 100 for fourth. Y1V5 p.18
  6. Rule An individual winner chooses 5000 private points or three written-test points, second chooses 3000 or two, third chooses 1000 or one; test points taken this way cannot be given to another student. Y1V5 p.19
  7. Rule The lowest scorer in an individual competition loses 1000 private points, or one written-test point if they hold fewer than 1000. Y1V5 p.19
  8. Rule Overall MVP takes 100,000 private points; each grade’s top three scorers take 10,000 private points apiece. Y1V5 p.19
  9. Rule The ten lowest-scoring students in each year lose ten points on their next written exam. Y1V5 p.20
  10. Rule Thirteen events in order: 100-metre dash, hurdle race, capture the flag (boys), ball toss (girls), tug-of-war by sex, obstacle course race, three-legged race, cavalry battle, 200-metre dash; then scavenger hunt, four-way tug-of-war, mixed three-legged race, and the mixed-grade 1200-metre relay. Y1V5 p.21
  11. Rule The participation table must be a class consensus; the window opens one week before the festival and closes at 5:00 pm the day before; a missed window means random assignment. Y1V5 p.22
  12. Rule Falling below the minimum for an all-participant event means disqualification; a recommended-event substitute can be bought for 100,000 private points per competition. Y1V5 p.22
  13. Rule Only the final event — the 1200-metre relay — brings all classes from all grade levels together; every other event is divided by grade level. Y1V5 p.26
