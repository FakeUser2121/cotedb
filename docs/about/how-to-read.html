How to read this site

Citations

A page reference such as p.47 follows that volume's page numbering: the number is the page marker in the corpus file for that volume, which for some volumes runs ahead of the numbers printed in the book. Where a volume's printed numbers differ, its volume page explains the offset. It is plain text, never a link: nothing opens when you click it. The volume is named next to it, as in Y1V1 p.47.

Status dots

● the volume, character or place has been read line by line. ○ only names and pages are recorded.

Line types

  • Spoken a line said aloud, quoted as printed.
  • Inner voice a thought or narration in the character's head.
  • What happens an action, in plain words.
  • Inference, not stated something the reader reasons out; it is never presented as fact.

Read up to

The menu at the top right hides every scene from volumes after the one you choose, so a page cannot spoil what you have not read. The choice is kept in this browser only.

Names

Names are shown with long-vowel marks. Search ignores them, so Kikyou and Kikyō find the same page.
