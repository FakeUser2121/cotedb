      Class Points

      points · generated view (source: cote_kb.db; regenerate with python3 kb/build_exam_dossiers.py)

      616 mentions · 30 vols · 3 claims

      Function

      Standing currency of the four classes: starts at intake, moves with every exam, sets the monthly private-point payout, and reaches Class A graduation value.

      Notes

      Intake baseline 1000 points — 'We had been given 1000 class points when we first came here' (y2v1 p.19) — though later intakes differ (this year's first-years started at 800, y2v12 p.28). Outside special-exam windows the index can only be lowered (decay periods, y2v5 p.30). Snapshot at March 1 of the second year: A 1098 (Sakayanagi) / B 983 (Horikita) / C 730 (Ryuuen) / D 654 (Ichinose), y2v12 p.13. Festival awards 100/50 (y2v5 p.14) and island first-place 300 (y2v5 p.187) are typical movement sizes. 616 mentions / 30 vols.
